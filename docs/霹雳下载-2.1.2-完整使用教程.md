# 霹雳下载 2.1.2 完整使用教程

霹雳下载是一款面向 macOS 的本地视频下载与媒体整理工具。它支持哔哩哔哩普通视频、AV/BV 编号、短链接、合集、分 P 视频，以及番剧 ss/ep 链接。应用在本机完成解析、下载、合并、记录和整理，不需要 Python、Homebrew、AI 订阅或手动输入下载命令。

> 请仅下载你有权保存的内容。软件不会绕过 DRM、会员付费、地区限制或平台访问控制。

## 一、系统要求与安装

- 系统：macOS 13 或更高版本。
- 处理器：Apple Silicon 与 Intel Mac 均支持。
- 安装：打开 `霹雳下载-2.1.2-macOS通用版-b47.dmg`，将“霹雳下载.app”拖入“应用程序”。
- 升级：先暂停任务并退出旧版，再用新版替换“应用程序”中的旧应用；不要同时运行新旧版本。
- 本版本尚未完成 Apple 公证。若系统拦截，请在“系统设置 → 隐私与安全性”中确认应用来源后再打开。

升级会沿用原有任务、账号和媒体库数据。安装、升级或删除任务记录不会自动删除已经下载的视频。

## 二、最快上手：下载单个视频

1. 打开“下载”页面。
2. 粘贴视频链接、AV/BV 编号或 b23.tv 短链接。
3. 点击“解析视频”。
4. 选择画质、MP4/MKV 容器和保存位置。
5. 点击“开始下载”。
6. 在任务队列查看速度、进度和剩余时间；完成后点击“在 Finder 中查看”。

应用会自动选取当前账号权限范围内可用的最高分辨率。音视频合并采用流复制，不进行二次转码，不主动降低原始画质。

## 三、整集/整季下载番剧

1. 复制番剧的 `ss` 整季链接或任意 `ep` 单集链接。
2. 粘贴到下载页并解析。
3. 在选集方式中选择：
   - “当前集”：只下载当前一集；
   - “指定范围”：填写开始集与结束集；
   - “整季”：下载官方正片目录中的全部可用剧集。
4. 选择画质、容器和保存文件夹。
5. 点击“开始下载”。

整季模式会按官方目录和集号顺序处理，排除预告等其他分区内容，并保存到对应合集子文件夹。已经确认存在的成品会自动跳过，适合补齐缺集。

## 四、多集一起下载

解析合集、分 P 视频或番剧后，可勾选多集或选择指定范围/整季，然后直接开始。每一集都是独立任务，多集可并发传输；无需手工逐集复制链接。

- 跨任务全局最多同时传输 4 集，其余自动排队。
- 普通机器每集自动使用 2–8 个连接；8GB 内存设备会收紧到最多 2 集、每集 4 个连接。
- 可单独暂停某一集，也可使用“全部开始”“全部暂停”“全部取消”。
- 多选任务支持 Shift/Command 点击及 `⌘A`。

并发上限是稳定性保护，不代表突破网站速度、账号权限或网络带宽限制。

## 五、同时下载多个链接

点击“增加链接”，可在同一组合任务中加入 1–4 条链接。各链接分别显示进度，链接内部按集序执行，不同任务之间可并行下载。取消组合任务会停止其中全部子任务。

也可点击左侧“新建任务”持续添加下载，或使用 `⌘N` 新建窗口。

## 六、暂停、继续与断点恢复

- “暂停”会真正停止下载进程并保存恢复状态。
- 下次启动时，中断任务显示“已中断，可继续”。
- 点击“继续”后会刷新临时授权地址并尽可能复用已有分片。
- 已完成文件会跳过；服务器不支持断点、格式已改变或分片被删除时，可能重新下载。
- 退出应用时会停止活动下载并保存任务状态。

关闭日志窗口或按 `Ctrl-C` 只会结束日志监看；请使用应用内按钮暂停或取消下载。

## 七、画质、容器与命名

- 画质：默认选择账号当前可用的最高分辨率，也可手动降低。
- 容器：默认 MP4，也支持 MKV。
- HDR/杜比视界：仅在来源确实返回对应动态范围时标识。
- Hi-Res：仅在平台返回相应音质且编解码信息匹配时标识。
- 网盘式命名：可按集号、标题、分辨率、编码、音轨和大小组合文件名。
- 合并后可依据实际媒体规格进行二次校正，减少文件名与成品规格不一致。

## 八、登录与会员内容

在“我的 B 站”中可：

- 使用应用内官方网页登录；
- 由用户主动选择 Chrome 用户并导入 B 站会话；
- 浏览账号收藏内容。

应用不保存账号密码；会话凭据写入 macOS 钥匙串。Chrome 导入仅由用户点击触发，只读取 B 站域名会话，不执行浏览器页面脚本，也不会上传凭据。会员身份只决定平台授权范围，软件不会绕过付费或 DRM 限制。

## 九、任务队列与历史记录

- 右侧任务队列可收起，支持搜索、多选和 `⌘A`。
- 可移除单条或批量任务记录；删除记录不会删除视频文件。
- 已移除记录可在归档页面查看或恢复。
- 每次下载会在保存目录写入“下载日志.txt”，记录来源、可读片名、文件名和结果，不记录会话凭据或媒体签名地址。

## 十、媒体库与识别

“媒体库”统一展示已下载内容，可搜索、分类筛选和定位文件。待识别内容也在同一入口中处理。

- 本地扫描建立稳定媒体索引；文件移动后可重新定位。
- 缩略图按需生成并使用有上限的内存/磁盘缓存。
- 可配置自己的 TMDB 读取令牌或 API Key，保存到系统钥匙串。
- 支持按季批量识别预览；确认匹配结果后再应用。
- 文件整理、重命名和删除前会先预览并要求确认。

TMDB 在线识别取决于用户自己的凭据与网络环境；下载功能不依赖 TMDB。

## 十一、常见问题

### 为什么解析不到某个视频？

常见原因是登录状态、会员权限、地区限制、平台风控、链接失效或接口变化。先确认网页端可以正常播放，再检查应用日志中的明确错误。

### 为什么没有最高画质？

应用只能使用当前账号和来源实际提供的格式。请先登录有对应权限的账号，再重新解析。

### 为什么下载速度没有继续提高？

连接数不是越多越快。速度还受家庭网络、磁盘、网站限速及服务器状态影响；默认并发策略优先保证整机稳定。

### 下载中断后会丢失进度吗？

应用会保存任务与检查点，并尽可能续传；但是否能从同一字节继续由服务器和现有分片共同决定。

### 日志在哪里？

运行日志位于 `~/Library/Application Support/PiliDownloader/Logs/`。日志会隐藏敏感链接，但可能包含视频标题、保存路径和观看偏好，请勿随意公开。
