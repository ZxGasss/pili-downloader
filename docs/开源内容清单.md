# 开源内容清单

## 应用源码

`Sources/` 包含下载入口、任务模型、官方 API、进度解析、断点恢复、媒体完整性、
本地分类、媒体库、账号安全、Chrome 会话导入、界面和硬件监测等 Swift 源码。

## 测试与验证

`Tests/` 包含共享核心测试、状态回归、暂停与续传、并发预算、合集范围、
分类与重命名、升级兼容、网络探针和公开测试夹具。

## 构建和打包

`scripts/build.sh` 构建 macOS 应用；`scripts/build-macos-universal.py`
生成 Apple Silicon 与 Intel 通用包；`scripts/test-state.py` 执行状态回归；
`scripts/verify.sh` 汇总本地验证。

构建需要 macOS、Swift 命令行工具和项目文档列出的第三方依赖。工具二进制、
构建缓存、DMG 和签名证书不提交到源码仓库。

## 平台代码

`platforms/windows/`、`platforms/android/` 和 `platforms/ios/` 保存辅助平台实现。
当前正式发布主线为 macOS 2.1.2；其他平台代码作为开源资料保留，不代表本轮已完成
同等验收。

## 文档与合规

- `README.md`：产品介绍、实际截图、安装和使用流程。
- `docs/霹雳下载-2.1.2-完整使用教程.md`：完整中文教程。
- `LICENSE`：MIT 许可证。
- `THIRD_PARTY_NOTICES.md`：第三方组件、许可证和源码获取说明。
- `SECURITY.md`：安全边界和漏洞报告方式。
- `ROADMAP.md`：后续维护方向。
- `CONTRIBUTING.md`：贡献与验证要求。

## 不进入公开仓库的内容

构建产物、下载媒体、用户任务历史、账号会话、临时 Cookie、TMDB 令牌、
本地绝对路径、缓存、日志、Developer ID 证书和私人测试数据不会提交。
