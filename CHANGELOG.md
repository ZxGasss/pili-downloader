# Changelog

## 2.1.2

- Reorganized the native workspace into navigation, download, media library,
  account, and task queue areas.
- Kept real process pause/resume, persistent checkpoints, missing-episode
  completion, and global resource budgeting.
- Added CPU-aware concurrent episode recommendations based on processor model,
  active cores, real-time load, and memory pressure.
- Preserved professional media naming with episode number, title, measured
  resolution, codec, audio format, and final size.
- Improved media library search, category filtering, relocation, and optional
  TMDB matching.
- Added public documentation, real screenshots, third-party notices, security
  policy, issue forms, and CI checks.

## 2.1.1

- Added low-memory safeguards for 8GB Macs.
- Added bounded image work and cache limits.
- Added native multi-selection and safer record removal.
- Improved account, favorite, media-library, and task-history handling.

## 2.1.0

- Unified the media library and unidentified-media workflow.
- Added optional TMDB credential validation and season-level matching.
- Added improved collection and bangumi directory handling.
